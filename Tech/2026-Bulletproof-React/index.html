30초 요약

  • 대부분 코드는 src/features/에 기능별로. 기능끼리 import 금지, 방향은 shared → features → app (ESLint로 강제).
  • 상태 5분류: 컴포넌트(useState) · 전역(zustand) · 서버캐시(react-query) · 폼(Hook Form+Zod) · URL.
  • 테스트는 통합 중심 + MSW. 에러 3층. JWT는 HttpOnly 쿠키.
  • 동봉 AGENTS.md가 AI 지시서 — "이 규칙대로 만들어" 한 마디면 됨.
  • 템플릿이 아니라 가이드. 원칙을 보고 도구는 갈아끼워도 된다.

상태 5분류 (외우면 절반)

분류해법주의

폼Hook Form + ZodForm·Input 추상 컴포넌트로 감싸기
URLrouter 파라미터·쿼리공유 가능한 상태는 URL에

API 레이어 3단

엔드포인트마다 ① 타입·검증 스키마 → ② fetcher (단일 api-client) → ③ react-query 훅. "정의된 엔드포인트 목록"이 한눈에.

테스트 · 에러 · 보안 · 성능

  • 테스트: 통합 중심. Vitest + Testing Library(행위 테스트) + Playwright + MSW(백엔드 없이 진짜 HTTP).
  • 에러: API 인터셉터(토스트·401 갱신) · 구역별 Boundary · Sentry+소스맵.
  • 보안: JWT는 HttpOnly 쿠키 (localStorage는 XSS 위험) · RBAC+PBAC · 입력 sanitize · 서버 검증 필수.
  • 성능: 라우트 코드스플리팅 · 상태 분할+colocation · children prop 최적화 · 고빈도 상태는 context 금지 · prefetch.

AGENTS.md — AI에게 그대로 먹이기

기능 개발 4단계: API 타입 → fetcher+훅 → UI → 통합테스트 → 라우팅. 컴포넌트는 Plop 제너레이터. Husky pre-commit(린트·포맷·TS)·pre-push(테스트). Standard 스택: React 18 + TS strict + Tailwind + Radix + TanStack Query + Zustand + Vitest/Playwright/MSW/Storybook.

React Native 적용

공식: "같은 구조를 React Native에 적용 가능". app/=네비게이션·프로바이더, features 동일. RN 추가분: 오프라인 캐시(entity model) · 푸시·딥링크(config) · 네이티브 모듈(lib). Expo면 FSD app/ 충돌 주의.
